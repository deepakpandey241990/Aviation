# Aviation

An open-source hub dedicated to aviation systems, Air Traffic Management (ATM), and communications engineering.

### Key Focus Areas
- **Communications, Navigation & Surveillance (CNS):** Technical tools, telemetry processing, and VHF R/T utilities.
- **Airspace & Routes:** Air Traffic Services (ATS) route waypoints, FIR structures, and navigation aid references.
- **Flight Ops & Logging:** Software scripts for channel transcription, flight data analysis, and ICAO Annex-compliant operational logs.
